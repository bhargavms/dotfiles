# WezTerm

Personal WezTerm config (part of [dotfiles](https://github.com/bhargavms/dotfiles)).

## Includes

- Login zsh, Rose Pine Moon / Gruvbox Light by system appearance
- 0xProto Nerd Font, single-tab bar hidden
- **Pane focus:** `Ctrl+Shift+h/j/k/l`
- **AeroSpace bottom strip:** reads `~/.config/aerospace/.wezterm-dock`

## Tabs / splits / workspaces

Use built-in WezTerm keys (defaults), e.g. `Ctrl+Shift+T` new tab, `Ctrl+Shift+%` / `"` splits, and the standard workspace actions from the WezTerm docs if you enable them.

For project multiplexing, use **tmux** or **Zellij** inside WezTerm instead of custom Lua.
